# Carte marine et navigation de base — Leçon 9

Leçon 9 couverte : lire une carte marine (SHOM), coordonnées, distances/vitesses, sondes et symboles, cap/route, calcul vitesse–temps–distance.

**Points clés enseignés :**
- Latitude (N/S, 0–90°, bords verticaux, donnée en premier ; mémo LAT≈ALT) ; Longitude (E/O, 0–180° depuis Greenwich, haut/bas) ; 1° = 60′
- 1 mille nautique = 1 852 m = 1 minute d'arc de latitude ; 1 nœud = 1 mille/heure
- Règle d'or examen : distances mesurées TOUJOURS sur l'échelle des latitudes (côtés), jamais sur les longitudes (car 1′ de longitude varie avec la latitude)
- Sondes = profondeurs (au niveau le plus bas → au moins cette eau sous la quille) ; symboles : danger/roche, épave, nature du fond (S sable, V vase, R roche), phare/feu, mouillage
- Clarification ajoutée (demande utilisateur, 2026-06-21) : SONDE = profondeur depuis le zéro hydrographique (plus basses mers astronomiques) ; HAUTEUR D'EAU RÉELLE = sonde + hauteur de marée à l'instant T ; SONDE DÉCOUVRANTE/ASSÉCHANTE = valeur SOULIGNÉE sur la carte = hauteur dont le fond émerge au-dessus du zéro (danger). Schéma + exemple chiffré + Q7/Q8 ajoutés. En Médit. marée < 30 cm → hauteur réelle ≈ sonde.
- Cap = direction de l'étrave (0–360°) ; Route = trajectoire réelle sur le fond (vent/courant peuvent l'écarter) ; nord vrai (carte) vs nord magnétique (compas) = déclinaison
- Rose des vents : 0° N, 90° E, 180° S, 270° O
- Formule clé : Distance = Vitesse × Temps (et dérivées). Convertir minutes en heures décimales (30 min = 0,5 h, 15 = 0,25, 45 = 0,75, 20 = 0,33)
- Carte officielle d'examen : SHOM 9999
