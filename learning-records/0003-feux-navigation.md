# Feux de navigation — Leçon 3

Leçon 3 couverte : les feux de navigation (RIPAM 20-31). Les 3 feux fondamentaux (rouge bâbord, vert tribord, blanc poupe/tête de mât), leurs secteurs, et les combinaisons qui permettent d'identifier le type de bateau et sa direction la nuit.

**Points clés enseignés :**
- Rouge = bâbord = gauche ; Vert = tribord = droite
- 4 feux de base et leurs secteurs (112,5°, 112,5°, 135°, 225°)
- Bateau à moteur = côtés + tête de mât + poupe (4 feux)
- Voilier = côtés + poupe (3 feux, pas de tête de mât)
- Mouillage = 1 feu blanc tout autour
- Lecture combinée des feux pour appliquer les priorités
- « Un peu de rouge à droite, ça m'inquiète »
