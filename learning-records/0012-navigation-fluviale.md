# Navigation fluviale (eaux intérieures) — Leçon 11

Leçon 11 : première leçon du volet FLUVIAL (objectif secondaire de la mission). Spécificités de l'option « eaux intérieures » par rapport au côtier.

**Points clés enseignés :**
- Permis plaisance = tronc commun + 2 options : côtière (mer, 6 milles) / eaux intérieures (rivières/canaux/lacs, bateau ≤ 20 m, dès 16 ans). Règlement intérieur = RGP / CEVNI (≠ RIPAM en mer)
- RIVE DROITE / GAUCHE définies face à l'AVAL (sens du courant). Vu vers l'aval : rive droite = balisage ROUGE, rive gauche = VERT ; marque jaune = traversée du chenal
- Panneaux (94 au total, carrés/rectangulaires) en 5 familles : interdiction / obligation / restriction (bordure ROUGE = ordre) ; recommandation (losanges vert-blanc, naviguer entre) ; indication (BLEU, picto blanc = info/autorisation)
- Vitesses en KM/H sur le fluvial (pas en nœuds)
- Règles : tenir sa droite → croisement bâbord-bâbord ; plaisance (menu bateau) s'écarte du commerce/convois ; bacs prioritaires ; le montant facilite le descendant
- Signaux sonores : 1 bref = tribord, 2 brefs = bâbord, 3 brefs = marche arrière, 1 prolongé = avertissement, série de brefs = danger
- Écluse (signalisation lumineuse) : 2 rouges (ou 1 rouge) = fermée/attendre ; rouge+vert = préparation ; vert = entrer. Dans le sas : pare-battages, s'amarrer av+ar, tenir les amarres à la main, moteur coupé, gilet
