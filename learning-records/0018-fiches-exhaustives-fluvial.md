# Fiches fluviales exhaustives (recherche vérifiée CEVNI/RGPNI)

**Déclencheur (utilisateur, 2026-06-22) :** « je veux des fiches extrêmement exhaustives, n'avoir que ça à réviser ; là il manque trop de choses. »

**Méthode :** 3 agents de recherche en parallèle sur sources officielles (CEVNI v5 UNECE — Annexes 3/6/8 ; RGPNI recueil 2019 ; Manuel CRR Fluvial ANFR ; RAINWAT ; mer.gouv.fr). Chaque fait vérifié + sourcé. Plusieurs corrections vs mes suppositions :
- Panneau bleu de croisement = + feu **BLANC** scintillant (pas jaune).
- Plongée = **pavillon A** (pas bicône rouge-blanc-rouge).
- Matières dangereuses : **1/2/3 cônes (ou feux) bleus → 10/50/100 m** (inflammable/santé/explosif).
- **2 feux blancs superposés = ancre dangereuse** pour la navigation (≠ protection remous = rouge sur blanc).
- Incapable de manœuvrer : jour pavillon rouge balancé OU 2 ballons noirs ; nuit feu rouge balancé OU 2 feux rouges.
- Bateau prioritaire = **flamme rouge de jour** (rien la nuit).
- **Montants cèdent aux avalants** (avalant moins manœuvrant).
- Dépassement **bâbord OU tribord** si sans danger (par défaut bâbord) = VRAI.
- Radio : procédure régie par **RAINWAT** ; **ATIS obligatoire** ; réduction puissance à ~1 W (sauf infos nautiques 25 W) ; accusé de détresse par un bateau si rien dans **1 minute** ; veille = **voie 10** (≠ canal 16) ; voie 70/ASN interdite en intérieur.

**Fiches produites :**
- NOUVELLE `reference/signaux-bateaux-fluviaux.html` : feux de route, incapable de manœuvrer, matières dangereuses (tableau cônes→distances), stationnement/remous/ancre, bacs/plongée/prioritaire, menue embarcation, détresse.
- NOUVELLE `reference/radio-vhf.html` : RAINWAT, 5 réseaux (tableau), ATIS, réduction puissance, MAYDAY/PAN PAN/SÉCURITÉ, accusé réception 1 min, CRR, canaux.
- ENRICHIE `reference/fluvial.html` : circulation (montant/avalant, panneau bleu, dépassement), signaux sonores complets (1/2/3/4/5 brefs, prolongés, dépassement, détresse), balisage du chenal (rives, bifurcation, bouées jaunes=baignade), vocabulaire (duc d'Albe, mouillage=profondeur, musoir, gabarit, étiage/crue…), vitesse/batillage/capacité (plaque signalétique)/coupe-circuit/amarrage/entonnoir/barrage.
