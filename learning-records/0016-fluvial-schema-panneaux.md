# Correction schéma rive droite/gauche + catalogue des panneaux fluviaux

**Déclencheur (feedback utilisateur, 2026-06-22) :** « les leçons fluviales sont légères, notamment les panneaux » + signalement d'un schéma incohérent (rive droite/gauche).

**1. Schéma rive droite/gauche (Leçon 11) — CORRIGÉ.**
- Erreur : en vue de dessus avec bateau pointant vers le bas (aval en bas), j'avais mis « rive droite (rouge) » à DROITE de l'image. Or un observateur qui regarde vers le bas a sa main droite vers l'OUEST = la GAUCHE de l'image → incohérent.
- Fix : réorienté avec **aval vers le HAUT**, observateur (bateau) en bas regardant vers le haut. Ainsi, face à l'avant, main droite = droite de l'image → **rive droite (rouge) à droite** est désormais correct ET intuitif. Légende mise à jour (« la main droite pointe la rive droite »).
- Leçon retenue : pour un schéma de latéralité, placer l'observateur en bas regardant vers le haut (vue « de derrière »), jamais en vue de dessus tête-bêche.

**2. Panneaux fluviaux — ÉTOFFÉS.**
- Nouvelle fiche `reference/panneaux-fluviaux.html` : catalogue imprimable de ~47 panneaux, classés séries A (interdiction) / B (obligation) / C (limitation) / D (recommandation) / E (indication), avec codes (A.1, B.6, C.2, E.5…), pictos schématisés et clé de lecture couleur/forme. Encadré « pièges » (P bleu vs P barré ; hauteur=tirant d'air vs profondeur=tirant d'eau ; chiffre rouge = km/h).
- Leçon 13 enrichie : 24 panneaux (ajout demi-tour interdit, moteur interdit, jet-ski interdit, tenir bâbord/tribord) + carte « catalogue complet » en intro + liens vers la fiche dans « S'entraîner ».
- Fiche `fluvial.html` : lien ajouté vers le catalogue.

**Sources :** Cerema/Ministère (guide signalisation navigation intérieure), virages.com (catalogue), RGP/CEVNI.
